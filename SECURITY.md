# Security and sensitive disclosures

Please do not open a public issue, pull request or discussion containing credentials, tokens, raw restricted data, private ASIE state, unpublished experiment artifacts or details that could reconstruct the private laboratory.

If you believe a public file exposes sensitive material, contact the repository owner privately through GitHub. Include the file path, commit and a short description of the exposure. Do not copy the sensitive content into the report.

The public repository is intentionally separate from the private `OI-Organoids-Intelligence` laboratory. A finding that belongs to the private environment should be removed from the public branch and handled there.
