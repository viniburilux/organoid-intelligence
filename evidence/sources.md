# Public source register

The public record uses primary or official sources whenever possible. The links below provide context for the field and the public artifacts used by the investigation.

| Source | Role in this record | Boundary |
|---|---|---|
| [Kagan et al., DishBrain](https://doi.org/10.1016/j.neuron.2022.09.001) | Primary context for a closed-loop biological neural-culture task. | The task-specific result is not general intelligence or consciousness. |
| [Brainoware](https://doi.org/10.1038/s41928-023-01069-w) | Primary context for organoid-based reservoir computing. | Source availability and task scope remain specific to the paper. |
| [Organoid Intelligence roadmap](https://doi.org/10.3389/fsci.2023.1017235) | Field-level agenda and terminology. | A roadmap is not an experimental demonstration. |
| [Goal-directed learning in cortical organoids](https://doi.org/10.1016/j.celrep.2026.116984) | Public paper associated with the processed artifact used in the first computational branch. | The public analysis does not reproduce the biological culture. |
| [Zenodo record 17684862](https://zenodo.org/records/17684862) | Public data and code artifact used for processed-table analysis. | The artifact and its license do not make raw biological experimentation reproducible. |
| [DANDI:001603](https://dandiarchive.org/dandiset/001603/draft) | Public dataset record providing NWB assets for the temporal branch. | The draft catalog is large and the available neural objects lack the aligned labels required for the original supervised task. |
| [Protosequences](https://github.com/braingeneers/Protosequences) | Public source-code and provenance context associated with the DANDI material. | Source context does not by itself resolve independence of repeated payloads. |
| [SpikeInterface](https://github.com/SpikeInterface/spikeinterface) | Open analysis framework context for neural data processing. | A tool is not evidence of a biological claim. |
| [OpenAlex](https://openalex.org/) | Public scholarly metadata context used in the initial field-validation stage. | Metadata discovery does not replace source-level verification. |

## How to read the sources

The source register provides context and provenance. The quantitative findings are summarized in [findings.md](findings.md), and their interpretation is bounded by [limitations.md](../docs/limitations.md). Public pages should not cite an external source as if it directly established a conclusion that was actually produced by a separate computational analysis.

## Third-party rights

Papers, datasets, code, names, logos and other external materials retain their own licenses and terms. This repository does not relicense them. Only original project documentation, summaries and small examples are covered by this repository’s license unless a file states otherwise.
