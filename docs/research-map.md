# Public research map

This map is the public counterpart to a much richer private research state. It exposes the shape of the investigation without publishing operational ASIE state, internal frontier scoring or unpublished laboratory machinery.

| Investigation | What the evidence showed | Public status | Next question |
|---|---|---|---|
| Field validation | Foundational claims, tools, licenses and dataset identities required source-level correction. | Consolidated | What new primary evidence changes a corrected claim? |
| Aggregate representations | Firing-rate and network summaries did not improve experiment-level prediction over simple baselines. | Closed for the tested setup | Which temporal representations are available without inventing labels? |

| Provenance | Different whole-file digests coexisted with equal targeted neural payloads in selected pairs. | Open contradiction | What upstream conversion or curation process produced this? |
| Synthetic control | The Sandbox demonstrates closed-loop computational control and explicit limits, not biological intelligence. | Draft public model | Can one shared action-scoring architecture isolate history access? |

## Reading the statuses

**Closed for the tested setup** means the exact question was answered under a defined protocol. It does not mean the topic is universally settled. **Blocked** means the current data boundary prevents a clean test. **Qualified positive** means the observed direction is supported but the stronger interpretation is not. **Open contradiction** means two observations coexist and the correct response is investigation, not narrative smoothing. **Draft public model** means the concept is exposed as an interface or research pattern, not as a validated scientific conclusion.

## Public state model

The internal project uses a richer state model. This public version is intentionally compact:

```yaml
question: "What can the available neural data support?"
hypothesis: "Simple temporal structure may carry short-horizon predictive information."
evidence: "Leakage-aware next-window tests across bounded sessions."
status: "qualified_positive"
contradiction: "File-level uniqueness did not guarantee targeted-payload independence."
next_move: "Reconcile provenance before making biological stability claims."
```

The public record is designed to show how state changes, not to expose the private machinery that schedules or executes every investigation.
