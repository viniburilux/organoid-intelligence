# Research timeline

The public record is a sequence of questions changing in response to evidence. Each step narrowed the next question instead of forcing the data into the original plan.

```text
Field validation
      ↓
Experiment 001 — first public artifact
      ↓
Experiment 002 — aggregate prediction
      ↓
Label audit — aligned labels unavailable
      ↓
Temporal branch — label-free next-window prediction
      ↓
INV-010/011 — burst/backbone structure and incremental signal
      ↓
INV-012 — contiguous-block and temporal-null stress test
      ↓
INV-013/014 — digest-aware replication and three-session synthesis
      ↓
INV-015/016 — provenance contradiction localized
      ↓
ASIE — research state and frontier model
      ↓
OI Sandbox — synthetic closed-loop control
```

## Field validation

The first stage checked public descriptions, papers, tools, datasets and licenses rather than accepting a broad model-generated inventory as fact. This produced a claims registry with confirmed, corrected, rejected, partial and unconfirmed records. Among the durable lessons were that task-specific learning is not general intelligence, a roadmap is not an experimental demonstration, and software licenses and dataset identities must be verified at the source.

## Experiment 001 — first public artifact

A manageable public artifact was selected to create an executable starting point. The project kept processed tables and manifests distinct from raw pickle execution, and treated the result as computational evidence rather than a reproduction of living tissue.

## Experiment 002 — aggregate prediction

The first predictive task used 32 complete experiments from 16 organoids and organoid-held-out folds. Aggregate firing-rate and network summaries did not beat simple baselines. This negative result made it harder to justify a shortcut from coarse summaries to performance.

## Label audit — the data changed the question

The public metadata and inspected NWB objects did not expose an aligned condition or performance label for the neural windows. The condition-supervised branch was blocked. The next question had to be label-free.

## Temporal branch

HO2 and HO3 spike data were converted into safe temporal representations. The first task was next-window prediction with simple baselines and time-blocked splits, avoiding learned embeddings until the data boundary was understood.

## Incremental temporal structure

Source-inspired burst/backbone features added predictive information beyond population-rate lags in the tested sessions. Stress tests and a digest-aware third-session replication strengthened the direction while preserving limits: the effect was narrow, heterogeneous and not a biological or cognitive claim.

## Provenance contradiction

Repeated assets with different whole-file digests contained exactly equal targeted neural arrays in selected pairs. This changed the interpretation of replication. The central open issue became source provenance and curation, not biological stability.

## ASIE and the research state

The private laboratory then formalized knowledge, questions, hypotheses, contradictions, unknowns, frontier items, cycles and budgets. The public edition presents that model conceptually, without exposing operational state.

## OI Sandbox

A separate synthetic branch tested closed-loop control, perturbations, memory windows, paired seeds and adversarial conditions. M2-E repaired one information confound but left a policy-class confound. The branch therefore remains a computational laboratory, not biological evidence.

## The principle of the timeline

> **The data determines the question. The question does not get to manufacture the data.**
