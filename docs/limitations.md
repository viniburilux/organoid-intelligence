# What we cannot claim

This page is part of the result, not a disclaimer added after the fact. The field of Organoid Intelligence combines biological experiments, computational models, interfaces, datasets and ambitious language. The public record keeps those layers separate.

## The project does not currently demonstrate

| Claim | Why it is outside the current evidence |
|---|---|
| Intelligence | The tested tasks are bounded prediction or synthetic control tasks, not a general intelligence assessment. |
| Consciousness or sentience | No experiment here measures or establishes subjective experience. |
| Biological memory | The synthetic memory tests do not identify a pure causal effect of history, and the real-data branch is label-free. |
| General learning | A short-horizon predictive signal is not a demonstration of general learning. |
| Experimental-condition decoding | The available neural objects lack a clean aligned condition label. |
| Performance decoding | Aggregate representations did not beat simple baselines for the tested performance target. |
| Independent biological longitudinal stability | Equal neural payloads in selected repeated assets require provenance reconciliation before independence can be claimed. |
| Equivalence between synthetic agents and organoids | The OI Sandbox is synthetic control infrastructure, not a biological simulator or organoid substitute. |
| A universal or first OI benchmark | The current record is a research program and prototype infrastructure, not a validated benchmark release. |

## The project does demonstrate

The public record supports a more limited set of statements:

- controlled computational experiments can be executed with explicit tasks, seeds, metrics and provenance;
- aggregate neural summaries can fail to improve prediction over simple baselines;
- simple temporal features can provide incremental short-horizon predictive information in the tested sessions;
- replication can expose a provenance problem rather than confirm the intended interpretation;
- missing labels can force a more defensible label-free question;
- contradictions and uncertainty can be carried forward instead of erased;
- a research-state model can organize knowledge, questions, hypotheses, contradictions, unknowns and next moves.

> The distinction between “does demonstrate” and “does not demonstrate” is the core design principle of this record.

## Scope boundaries

The public repository contains curated summaries and small examples. It does not include operational ASIE state, internal frontier choices, raw or restricted data, acquisition credentials, unpublished experimental machinery or the complete private execution environment. The absence of those files is deliberate: this repository is a public research record, not a public copy of the laboratory.

## Source context

The biological field context includes DishBrain, Brainoware and a published Organoid Intelligence roadmap, but each source has its own task, substrate, protocol and evidence level.[1] [2] [3] The claims made here are narrower than the claims made by any individual source.
